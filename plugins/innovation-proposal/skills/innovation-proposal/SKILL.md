# 创新创业大赛项目策划书写作

为参赛团队产出一份能拿分的策划书：结构锚定所参赛赛事的评分表，每一个评分要点都有对应的章节和证据去回应。基准框架与逐章写作法对所有商业计划书类赛事通用；赛事差异通过参考文件路由。

## 第一步：确认赛事、赛道组别与素材

用 AskUserQuestion 一次问清（用户已在请求里说明的信息不要重复问）：

1. **参加哪个赛事**——中国国际大学生创新大赛（原"互联网+"）/ 挑战杯 / 创青春 / 三创赛 / 服务外包 / 大创计划（国创）/ iCAN / 其他或省级校级。用户没提赛事时，默认按中国国际大学生创新大赛处理，并说明这一假设。
2. **赛道与组别**（如大创赛的高教主赛道创意组、三创赛的常规赛/实战赛）——见对应参考文件。用户说不清时按通用组别处理。
3. **项目素材**——项目一句话定位；解决什么问题；已有什么（技术/专利/软著/论文/调研数据/订单营收/团队背景/指导教师）；有没有校方统一的策划书模板或页数要求。
4. **交付格式**——默认 Word（.docx），可另存 PDF。

**如果校方发了模板**：以校方模板的章节框架为准，本 skill 的大纲让位于模板，但每章内容仍按评分要点充实。

## 第二步：获取该赛事的评分规则（按优先级路由）

按以下顺序确定评分依据：

1. **用户能提供当届官方评分表**（文本/截图/文件/链接）→ 最高优先级，直接用它。
2. **中国国际大学生创新大赛** → 读 `references/judging-criteria-2026.md` 中对应赛道组别的评分表原文（2026年官方全文）。
3. **其他赛事**（挑战杯/创青春/三创赛/服务外包/大创/iCAN/省校赛）→ 读 `references/competition-map.md` 的速查表与该赛事典型框架。
4. **未收录且拿不到评分表** → 用 `competition-map.md` 的"通用五维兜底框架"。

读完记住三件事：

- **分值权重**：创新性与商业性/可行性通常合计过半，是写作主战场；篇幅与详略按分值分配。
- **调研真实性是普遍得分点**（大创赛2026版"个人成长"维度明文要求）：必须显性写出调研过程（时间、地点、方法、样本量）、项目与课程/专业/科研训练/社会实践的联系、指导教师与成员的实质性贡献。
- **红线**：几乎所有赛事都规定材料弄虚作假、抄袭剽窃一票否决。因此：

> **绝对不编造数据、专利、奖项、合同、用户数、财务数字。** 素材缺失时先向用户索要；用户确实没有的，文中标 `【待补充：具体缺什么】`，交付时汇总成清单让团队填。宁可留白，不可造假。

## 第三步：定制大纲

读 `references/outline-and-writing.md`，以 16 章商业计划书大纲为基线，按赛事/组别调整（组别变体、研究型申报书结构见该文件与 competition-map.md），按分值权重分配篇幅。先把大纲（章节标题 + 每章要点 + 页数分配 + 待补充素材清单）给用户确认，再动笔写正文。

## 第四步：逐章撰写

- 每章开头想清楚"这一章回应评分表里的哪一条"，用评审语言组织内容（如创新点对应"产品创新、工艺流程创新、服务创新、商业模式创新"四个抓手）。
- 断言必有支撑：市场规模给口径和来源，效果给数据，团队给分工与实质性贡献。
- 语言具体、克制，删空话套话（黑名单见 outline-and-writing.md）。
- 数据缺口一律标 `【待补充】`，不要顺手填一个"看起来合理"的数。

## 第五步：生成文档并自查

1. 调用 `document-skills:docx` skill 生成 Word：封面（项目名称、赛事与赛道组别、学校、负责人、指导教师）→ 目录 → 正文 → 附件清单。图表用表格与编号呈现。生成后务必做两类渲染自检：**页底孤行标题**（标题段落加 keepNext、标题后首段加 keepLines）和**目录页码**（目录占位页码按实际排版回填，并保留"右键更新域"提示）。
2. 按 `references/quality-checklist.md` 全文自查（其中 B 节按本赛事评分表替换为对应维度）。
3. 交付时附上两样东西：**评审维度对照表**（每个评分维度 ↔ 策划书章节 ↔ 对应证据）和**待补充信息清单**。
