# 交付前自查清单

交付策划书前逐项过一遍。任何一项不过，修完再交付。

## A. 红线（必要条件，触碰即一票否决）

- [ ] 无任何编造：每一个数据、专利、奖项、合同、营收、用户数都来自用户提供的真实材料或公开可查来源
- [ ] 所有"已获/已授权/已签约"表述能在附件中找到对应佐证
- [ ] 无抄袭痕迹；引用行业数据均注明来源（报告名、年份、机构）
- [ ] 红旅赛道：文中写明参加过"青年红色筑梦之旅"活动（时间/主办方）
- [ ] 待补数据全部以【待补充：××】标注，未被臆造数字顶替

## B. 评分维度覆盖（对照所选题道的评分表逐条核）

**个人成长（25–30分，最易失分）**
- [ ] 写明了调研的时间、地点、对象、方法、样本量，并有一手数据呈现
- [ ] 写清了项目与课程/专业/实验/科研训练/社会实践的联系（项目"从哪里来"）
- [ ] 有院校支撑：大创立项、实验室、孵化基地、导师课题等（如实）
- [ ] 体现"四新"建设与产教融合/科教融汇/专创融合/产学研（对应到具体事实）
- [ ] 体现项目对团队成员成长的锻炼（知识应用、能力提升）

**项目创新（20–30分）**
- [ ] 创新点按官方抓手分类陈述（产品/工艺流程/服务/商业模式创新，或对应赛道的变体）
- [ ] 每个创新点有对比对象和支撑证据（专利号/检测报告/数据）
- [ ] 从创意到研发、试制、生产、进入市场的过程链条完整可见

**产业价值（25–30分）**
- [ ] 产业认知四件套齐：规模、增速、竞争格局、产业政策，均有来源
- [ ] 目标市场定位明确，TAM/SAM/SOM 推算过程可复现
- [ ] 商业模式完整：谁付费、定价、成本、获客
- [ ] 创业组：经营绩效、经营管理、财务管理、成长前景逐一落实
- [ ] 社会影响：带动就业数量与质量、对社会文明/生态/民生的作用

**团队协作（15–20分）**
- [ ] 逐人写实质性贡献（2026新增"团队贡献"评分点），指导教师的指导内容具体
- [ ] 组织构架、分工、能力互补、激励（创业组含股权）齐备
- [ ] 写了团队对项目的投入与团队-项目真实性

**赛道专属**
- [ ] 红旅公益组：明确不以营利为目标；有公益成果与可复制推广模式
- [ ] 职教赛道：体现职普融通/产教融合/大国工匠培养要素
- [ ] 产业命题组：命题要点逐条回应，方案匹配度明确
- [ ] 萌芽赛道：体现学生自主性，科技/专利有佐证

## C. 内容质量

- [ ] 执行摘要一页内含：问题、方案与创新、进展数据、团队，无空话
- [ ] 痛点-方案-市场-财务的数字链条一致（收入假设能追溯到市场分析）
- [ ] 无空话黑名单词汇（填补国内空白、行业领先、潜力巨大……）
- [ ] 每章开头能回答"这章回应评分表哪一条"
- [ ] 风险章是真风险，应对可操作
- [ ] 页数符合校赛/省赛要求（如有限制）

## D. 格式

- [ ] 封面要素齐：项目名称、赛道与组别、学校、负责人、指导教师、日期
- [ ] 目录与正文标题一致；页码完整；图表统一编号且在文中被引用
- [ ] 附件清单与正文"见附件X"一一对应

## E. 交付时随文附上

1. **评审维度对照表**：评分维度 | 分值 | 策划书对应章节 | 支撑证据（附件编号/正文页码）——让团队和指导教师一眼看到每分落在哪。
2. **待补充信息清单**：所有【待补充】项的汇总，注明"哪一章、需要什么、建议找谁要"。
