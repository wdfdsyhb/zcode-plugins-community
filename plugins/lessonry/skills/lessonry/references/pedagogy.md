# pedagogy.md — 教学法规范

> 目标读者默认是**中文零基础小白**。本文件规定"教什么、按什么顺序教、用什么口吻教"。
> 目录：[1. 大纲设计] [2. 章节五件套] [3. 公式规范] [4. 口吻与措辞] [5. 数字一致性] [6. 反模式]

## 1. 大纲设计（由浅入深）

一页 = 一个主题，8±2 章。动笔前先写大纲，每章回答一个问题：

```
第 0 章  一分钟速览     —— 这个主题是什么、属于哪个领域、读完有什么用（三卡片 + 路线图）
第 1 章  直觉章         —— 一个生活类比建立第一印象（蒙眼下山 / 带权查字典 / 集装箱…）
第 2-N 章 主体章        —— 概念逐层递进：先动机（为什么需要它）→ 再是什么 → 再怎么算
核心章(★) 1-2 个        —— 全页最重要的机制，步骤最多、动效最足，标题加 ★
倒数第 2 章 进阶/实战   —— 真实世界的做法、工具名、常见坑
最后一章 全景+综合测验  —— 与其他知识页的连线图 + 5 题综合测验
```

排序检验：**任何一个后章用到的概念，前章必须已经讲过**（或一句话现场解释）。
类比要贯穿：第 1 章选定的类比（如"查字典"）在后续章节持续复用并保持映射一致。

## 2. 章节五件套（每章固定闭环，顺序不可乱）

```html
<section class="card" id="secN">
  ① 橙色 note    <div class="note"><b>讲解要点：</b>动机 + 类比 + 本章预告</div>
  ② 播放器       controls(▶⏭↺) + caption + svg + scroller
  ③ 图例         <div class="legend"> 颜色 → 含义，逐项对应 SVG 里用到的颜色
  ④ 绿色 recap   📌 一句话总结（可背） + ✅ 自查（自检问题 + 括号给答案）
  ⑤ quiz 容器    <div class="quiz" id="quizN"></div>（JS 里 initQuiz 填充，通常 1 题/章）
</section>
```

- 播放器步骤字幕 = "讲故事的声音"：n/N 递进，每步只讲一件事，字幕与画面**必须**同步。
- 步骤数 4-8 步为宜；第一步永远是"建立场景"，最后一步收束到本节结论。
- 交互件（滑块实验室/点击探索/计算器/终端模拟）可以替代播放器放在主体章，但五件套结构不变。

## 3. 公式规范（核心：绝不空投公式）

公式出现必须走完四步，缺一不可：

1. **先给具体数字例子**——用 3 个小数字把结果算出来（如"点积 1×2+0×1+2×1 = 4"）。
2. **再给公式**——放在 `.formula` 块，KaTeX 渲染（`data-tex` + `data-plain` 降级）。
3. **逐符号点名**——公式里每个符号用大白话解释（"η 是步幅"、"∇L(w) 读作 w 处的梯度"、
   "ᵀ 表示把 K 竖着摞成矩阵"）。符号首次出现处解释，不放到页尾。
4. **变式练习**——quiz 换一组数字让读者自己算（解析里给出完整推导）。

符号统一：全页只用一套符号（要么 w 要么 θ，不许混用）。同一符号在两处语义相反时
（如温度 τ 一处当除数一处当乘数）必须显式说明，否则删掉一处。

## 4. 口吻与措辞

- 对"你"说话："你会明白…""亲手调它""你已经读懂了…"。
- 每个黑话**首次出现**处给括号白话：`token（词元，模型处理文字的最小单位）`、
  `过拟合（背熟训练题、新题反而错）`。宁可啰嗦一次，不让读者卡住。
- 类比映射写明：`Query = 你想查的词（的"问题"），Key = 每个词条的"索引标签"`。
- 数字口径统一：倍数/折扣不混用（"省 8 倍"= "降到原来的 1/8"，不说"打 1.25 折"这种歧义话）。
- 章节间互相引用要具体："⑦ 的 KV Cache（第 2 章）"，不用"下轮/下下页"这类模糊指路。
- 单位写法全页统一（FLOP/Byte，不要一会儿 FLOPs/Byte）。

## 5. 数字一致性（验收必查）

- 页面里同一组数字只允许一个口径：图上画的、字幕说的、quiz 答案算的必须完全一致。
- 所有"实算"例子必须真的算得平（0.46+0.35+0.19=1，不是 1.01）。
- 涉及真实硬件/模型的数字标注"公开规格近似值/教学示意"。
- 互动件的输出文字由同一数据源渲染（如 PLANS 对象），避免图和文字各写一份。

## 6. 反模式（历史事故，禁止重演）

| 反模式 | 正确做法 |
|---|---|
| 公式先甩出来，符号后补甚至不补 | 走第 3 节四步 |
| 步骤字幕说 A，画面高亮 B | 写每步时同时核对高亮目标 |
| 黑话用到第 5 次还没解释 | 首次出现处给括号白话 |
| 同一数字多处手写、互相打架 | 单一数据源渲染 |
| "打几折/省几倍"混用 | 全页统一一种口径 |
| 类比映射前后不一致（前文 Query=查的词，后文变掉） | 大纲阶段定死类比映射表 |
