## P1 并排对比动画（对立概念）
两个底板框（如 CPU vs GPU、prefill vs decode），各自的元素按各自节奏出现。
- 适合：A 和 B 的哲学差异。关键：左右布景对称，caption 交替讲两边。
```js
boxRect(svg,40,40,440,420,'#fdf6f1',{stroke:'#e8c9a8'});   // 左卡
boxRect(svg,560,40,440,420,'#f1f5f9',{stroke:'#b7cede'});  // 右卡
```

## P2 流水线接力（多阶段流程）
一排 chip 节点 + 箭头，packet 沿箭头流动，流到哪哪个节点 pulse。
- 适合：请求处理、数据管线、YAML 提交后发生什么。节奏：每个节点一步。

## P3 公式点亮（实时公式）
SVG 里放公式的"分块文字"（每块一个 txt），步骤进行到哪，对应块变色/点亮。
- 适合：多步计算（打分→缩放→归一化→加权求和）。配合下方"实算数字"同步变化。

## P4 网格铺满（并行直觉）
几行几列小方块，逐个或整批变色，表示"千万个工人同时上"。
- 适合：GPU 线程、并发副本、batch。左路对比：queue 数组逐个出现（排队）。

## P5 可点击探索（信息分层）
SVG 元素绑 click，点击后把该元素详情写进旁边 `.stat` 面板。
- 适合：内存金字塔、架构图（点组件看职责）、对象模型。
```js
groups.forEach((g,i)=>g.addEventListener('click',()=>select(i)));
function select(i){ statEl.innerHTML = layers[i].stat; /* 同时高亮选中层 */ }
```
- 注意：默认 select 一个（进入章节即有内容，面板不空）；详情面板底部加一行"👆 点击…切换"提示。

## P6 滑块实验室（亲手玩坏）
`pg-row` 滑块 + 预设按钮 + `.stat` 读数面板；render() 由输入驱动重画。
- 适合：学习率、算术强度、KV 显存账等"参数→结果"直觉。设计要点：
  - 预设按钮覆盖"太小的/合适的/太大的"三个剧点（如 0.05 / 1 / 2.2）；
  - 读数面板给出判定文案（"✅ 收敛 / ⚠ 震荡 / 💥 发散"）；
  - 判定阈值与动画行为必须来自同一数据源。

## P7 终端模拟（命令实操）
按钮列表 + 黑底终端 div；点击按钮逐字打出命令与输出。
- 适合：kubectl/git/CLI 教学。输出必须是真实命令的真实输出结构（模拟数据、结构真实）。

## P8 堆叠条形图（构成/预算）
横条分三段（权重/KV/开销…），按方案数据渲染，附容量红线（如 80GB 竖直虚线）。
- 适合：显存构成、成本构成。关键：红线要"竖直地画在轴的对应位置"并有标签；
  数字结论（"还剩 46.8G"）由同一数据计算，不手写。

## P9 代码逐行高亮
`<pre class="code">` 每行一个 `<span class="ln" id="clN">`，步骤里 `hl([1,3])` 切换 `.on`。
- 适合：讲一段真实代码。⚠ `pre.code` 是 `white-space:pre`，`.ln` 必须 `display:block`
  （模板 CSS 已含），否则所有行挤成一行。长行允许横向滚动。
- 每步高亮的行与字幕讲的内容严格对应；代码里配 `# ←` 白话注释。

## P10 轨迹/等高线（优化过程）
背景等高线（同心椭圆 path），几条不同颜色的轨迹 polyline 从同一起点出发 draw()。
- 适合：梯度下降、迭代过程。标签加白底板防轨迹穿字（见 checklist 已知坑）。
