# 风格原型库（Style Archetypes）

> 用途：AI 写前端前，**先在这里选一种风格原型作为气质方向**，再按该风格的参数落地。
> 这么做是为了对抗「默认单调」——无方向地均匀用力会让页面平淡。先定气质，再执行。
> 同目录归属：references/（四支柱之一，对应「先选谁」）。

## 使用方式
1. 根据页面类型 / 品牌调性 / 目标用户，从下表中**只选一种**（可为主风格+微调，不要混搭多种气质）。
2. 把选中的风格参数（色调倾向、字体、间距、动效）应用到 design-tokens 与组件样式。
3. 在代码/说明中注明「本页面采用：极简克制风」，保持风格贯穿始终。

> ⚠️ 借鉴原则：以下代表网站只用于**提炼气质与原则**，绝不复制其像素、文案或品牌元素。

---

## 1. 极简克制风（Minimal / Apple 式）
- **气质**：大量留白、克制、专注产品本身、干净利落。
- **色调倾向**：中性色为主（白/浅灰/深灰），单一强调色，几乎不用彩色渐变。
- **字体搭配**：现代无衬线（SF Pro / Inter / Helvetica 系），字号偏大，正文简洁。
- **间距气质**：宽松（大间距），呼吸感强。
- **动效气质**：极慢、极柔的淡入淡出，尽量少的位移。
- **质感细节**：细边框或极浅阴影，几乎不用渐变。
- **代表参考站**：Apple、Linear、Stripe(部分页面)。
- **适用场景**：SaaS 官网、产品说明、高端品牌落地页、开发者工具。

## 2. 玻璃拟态与光效（Glassmorphism）
- **气质**：通透、发光、未来感、梦幻科技。
- **色调倾向**：深色底 + 半透明白/彩色光斑背景，前景面板用 backdrop-blur 玻璃。
- **字体搭配**：纤细或中等字重的无衬线，靠光效衬托。
- **间距气质**：中等偏宽松。
- **动效气质**：柔和的悬浮、光斑漂移。
- **质感细节**：半透明背景 + 1px 内边框 + 大模糊 + 柔和提亮。
- **适用场景**：音乐/游戏/科技产品的质感展示页、Dashboard 的装饰性背景。

## 3. 编辑排版风 / 接近纸质（Editorial / 杂志式）
- **气质**：留白大、网格明显、字体有性格、像高级杂志或纸质刊物。
- **色调倾向**：大量白/米白背景，黑文字，少量单色点缀。
- **字体搭配**：衬线体（Serif，如 Georgia / 宋体系）+ 无衬线混搭，标题字号极大，正文行高舒适。
- **间距气质**：网格严谨、列与留白讲究。
- **动效气质**：克制，聚焦于滚动节奏与图片渐入。
- **适用场景**：媒体、品牌叙事页、传记/作品集、长文阅读页。

## 4. 大胆撞色（Bold / Playful）
- **气质**：自信、活泼、年轻、高饱和、强记忆点。
- **色调倾向**：高饱和主色 + 撞色次色（如蓝+橙、紫+黄），常用大面积色块。
- **字体搭配**：圆润或厚重字重，可带夸张字号对比。
- **间距气质**：紧凑但分层清晰，色块即分隔。
- **动效气质**：活泼、有弹性、悬停微动。
- **适用场景**：面向年轻用户的品牌页、教育/游戏/活动落地页、个人作品集。

## 5. 深色高级感（Dark Premium）
- **气质**：沉稳、高级、夜间模式、突出内容本身。
- **色调倾向**：深蓝/深灰黑底，主色为一种低饱和强调色（如青、琥珀、电光蓝），文字高对比。
- **字体搭配**：中字重无衬线，靠字色对比建立层级。
- **间距气质**：适中，善用深色留白。
- **动效气质**：细微、平滑、不发散。
- **质感细节**：低强度阴影 + 高光描边，避免纯黑（用 #0f1115 这类带色相的黑）。
- **适用场景**：终端/开发者工具、游戏 Dash、科技品牌、沉浸式体验。

## 6. 柔和拟态 / 毛玻璃面板（Soft UI / Neumorphism-lite）
- **气质**：柔和、亲切、可触摸、圆润。
- **色调倾向**：低饱和同色系底，元素用同底色阴影（明/暗双向）营造凸起。
- **字体搭配**：圆润无衬线，字重适中。
- **间距气质**：紧凑圆润，组件间距小但层级清晰。
- **动效气质**：轻微按压反馈。
- **质感细节**：大圆角 + 柔和对角阴影（内阴影/外阴影）。**注意**：适度使用，避免平浅无对比、可访问性差。
- **适用场景**：移动端工具、卡片式面板、管理员面板的局部装饰。

## 7. 精简数据仪表盘风（Data-dense Clean）
- **气质**：信息密度高但清晰、效率优先、专业。
- **色调倾向**：浅底 + 中性文字，强调色用于数据/状态，多用于图表。
- **字体搭配**：紧凑无衬线，等宽字体用于数据/代码。
- **间距气质**：紧凑但对齐严格，网格分明。
- **动效气质**：图表入场动画、数值滚动，克制。
- **质感细节**：细分隔线、紧凑表格、清晰的状态色（成功/警告/错误）。
- **适用场景**：Dashboard、B2B 后台、监控系统、报表页。

## 风格速查对照表
| 风格 | 文字基调 | 代表点 | 最适合 |
| --- | --- | --- | --- |
| 极简克制 | 白/灰底 + 中性色 | 留白 | SaaS 官网、产品页 |
| 玻璃拟态 | 深色 + 半透光 | backdrop-blur | 科技质感页、装饰性 Dash |
| 编辑排版 | 米白 + 衬线 | 网格 + 大标题 | 媒体、叙事页 |
| 大胆撞色 | 高饱和色块 | 对比冲击 | 年轻品牌、活动页 |
| 深色高级 | 深底 + 单强调色 | 沉浸 | 开发者工具、夜间产品 |
| 柔和拟态 | 同色系低饱和 | 圆角阴影 | 卡片面板 |
| 数据密集 | 浅底 + 紧凑 | 信息清晰 | Dashboard、后台 |

> **反单调提示**：即便选了某风格，也要在**统一中制造对比**（见 knowledge/设计原则.md）——一个焦点按钮、一处大标题、一处分隔色，让视线有落点。
