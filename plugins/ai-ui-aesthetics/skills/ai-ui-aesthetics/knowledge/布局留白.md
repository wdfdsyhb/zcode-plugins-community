# 布局与留白（知识：间距系统、网格、节奏、视觉重量）

> 布局决定「节奏」与「呼吸」。统一且分层的间距，是一眼专业感的来源。

## 1. 基底间距系统（4px 尺度）
以 4px 为最小单元，间距只用「倍数」：
- **4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96**
- 组件内小间距：4–8px；组件间：16–24px；区块间：48–96px；页面级：96–128px。
- **铁律**：任何间距都取自这套尺度，禁止随手 13px、19px 这种散值。

> 等价于 tokens 里的 `--space-1 … --space-9`（见 tokens/design-tokens.md）。

## 2. 留白（Whitespace）
- 留白是主动的设计，不是「剩下的地方」。
- 保守原则：**宁可多留白，不要拥挤**。留白多 → 高级、专注；拥挤 → 廉价、焦虑。
- 把重要元素周围留白加大，视觉上「抬举」它。
- 移动端也要留出足够边距（至少左右 16px，不要贴边）。

## 3. 网格（Grid）
- 用栅格（如 12 列）排版，容器限宽（如 1120–1200px），居中。
- 列与列之间用统一 gutter（如 24px）。
- 大区块用整列，小元素可占子列，保持对齐。
- 响应式：见 rules/响应式.md 的断点。

## 4. 视觉重量与平衡
- 大块（图片、色块、标题）重 → 用留白与分组平衡。
- 别让所有内容堆在一侧/一角；但「不对称平衡」也可是刻意设计。
- 对称很稳，非对称有张力——选一种并坚持。

## 5. 节奏（Rhythm）
- 通过间距的「松-紧-松」制造节奏：重要区块间距大，相关组内间距小。
- 对比「组内紧密、组间宽松」的分组法，让页面有层次流动。
- 附图/卡片：用统一间距网格排布，规整又不死板。

## 6. 布局常见错误
| 错误 | 修正 |
| --- | --- |
| 间距随手乱填 | 一律走 4px 尺度 token |
| 全页面挤在一起没留白 | 加大区块间距，给重点元素孤立空间 |
| 内容贴边/顶到底 | 容器限宽 + 页面边距（24–48px） |
| 长度参差没对齐 | 网格对齐，统一 gutter |
| 区块没有分组逻辑 | 用「相近则聚」+卡片/分隔线分组 |

## 7. 一句话
**布局 = 用 4px 尺度的间距和清晰的网格，把内容编排成有节奏、有呼吸、有重点的秩序。** 先定网格，再定区块间距，最后填内容并校准留白。
