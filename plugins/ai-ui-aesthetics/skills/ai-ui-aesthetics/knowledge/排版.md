# 排版（知识：如何建立清晰的视觉层级）

> 排版是「单调→好看」最立竿见影的一环。好看的排版几乎总是**层级分明的排版**。

## 1. 排版的本质是「分层」
合理的页面文字分成层次：**标题 → 副标题 → 正文 → 标注（caption）**。
每个层级用「字号 + 字重 + 颜色 + 行高」组合，让读者一眼看到重点。

| 层级 | 建议字面（比例） | 字重 | 颜色（对比正文） |
| --- | --- | --- | --- |
| 展示/大标题 Display | 40–64px+ | 600–800 | 最深 |
| 标题 H1/H2 | 24–36px | 600–700 | 深 |
| 副标题 H3/H4 | 18–22px | 500–600 | 中深 |
| 正文 Body | 15–17px | 400–500 | 标准 |
| 标注/Caption | 12–14px | 400–500 | 更浅/次级 |

> 关键：**同一层级的字号只需相差一到几档**，再用字重与颜色放大差异，避免「每个标题都不一样大」的混乱。

## 2. 字体选择
- **无衬线 Sans**：现代、通用、屏幕可读：Inter、系统字体栈 `-apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`。
- **衬线 Serif**：编辑风/杂志感、有性格：Georgia、宋系、Playfair。
- **等宽 Mono**：数据/代码/数字表格：`ui-monospace, SFMono-Regular, Menlo, monospace`。
- **字体配对铁律**：一个页面**最多两种字体家族**（如 标题衬线 + 正文无衬线），且保证风格协调。汉字注意中文字体栈与字重。

## 3. 行高与字距
- **正文行高 line-height**：1.5–1.7（太紧挤、太松散）。
- **标题行高**：1.1–1.3（标题可紧一点，显大气）。
- **大标题字距 letter-spacing**：可负一点点（-0.02em~-0.04em），显得紧凑高级。
- **标注/按钮字距**：可加一点点（0.01–0.06em，全大写英文尤其需要），显精致。
- **段落宽度**：正文每行约 45–75 字符（约 600–700px），超长难读。

## 4. 页边距与段落间距
- 段落间距 ≥ 行高（用 margin 而非空行），用间距划分语义而非靠换行。
- 区块间距保持一致（见 knowledge/布局留白.md 的 4px 尺度系统）。

## 5. 中文排版注意（重要）
- 中文标题用**中文字重足够**的字体（思源黑体 / HarmonyOS Sans / 系统黑体），避免细字重发虚。
- 中文行高取 1.6–2.0 更舒适（汉字无字母上下延伸，需更多行高）。
- 中英文混排时对数字/英文可用等宽或统一字体栈，保证对齐。
- 避免大段斜体中文（难读）。
- 段首不缩进或用统一间距，中文字号通常 14–17px 为宜。

## 6. 常见排版错误
| 错误 | 修正 |
| --- | --- |
| 所有文字一样大、一样重（单调主因） | 明确分层：大标题/正文/标注各司其职 |
| 字号层级过多 | 收敛为 4 层，靠字重/颜色拉差 |
| 正文行高过小 | body 行高 ≥1.5 |
| 中文字重过细 / 发虚 | 用 500+ 字重，避免 300 细体做正文 |
| 段落间用「空行」代替 margin | 用统一的 margin，保持间距一致 |
| 正文过宽 | 限宽 600–700px |

## 7. 一句话
**好看的排版 = 用「字号×字重×颜色×行高」把信息讲成一个有轻重缓急的故事。** 先定层级，再选字体，最后校准行高与间距。
