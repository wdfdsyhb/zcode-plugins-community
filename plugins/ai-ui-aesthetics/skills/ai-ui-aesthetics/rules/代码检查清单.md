# 代码检查清单（写码前/后自检 checklist）

> AI 写完前端后，**逐条对照**本清单，不达标就改。这是保证「美」能落地的收尾关卡。

## A. 统一性（System）
- [ ] 所有颜色/圆角/阴影/间距/动效引用 tokens，无裸值（#fff、16px、2px 随手）？
- [ ] 同语义（主/次/ghost 按钮、卡片、输入框）全站视觉一致？
- [ ] 全站只有一套圆角、一套阴影分层、一种主色？

## B. 层级与对比（Hierarchy & Contrast）
- [ ] 页面有明确的视觉焦点（主体/主按钮/大标题）？
- [ ] 标题/正文/标注字号字重有层级差异，而非全篇一样？
- [ ] 文本与背景对比度达标（正文 ≥4.5:1，大字号 ≥3:1）？
- [ ] 高饱和色仅用于小面积（文字/强调/按钮），不作大面积背景？

## C. 间距与留白（Spacing & Whitespace）
- [ ] 间距全部来自 4px 尺度 token（4/8/12/16/24/…），无散值？
- [ ] 区块间留白足够，重点元素有独立空间，无拥挤？
- [ ] 移动端左右留白 ≥16px，无贴边？

## D. 布局与响应式（Layout & Responsive）
- [ ] 页面四周对齐到网格，无内容参差错位？
- [ ] 在 360px 与 1400px 下无横向滚动、层级保持、图片不溢出？
- [ ] 多列在窄屏降为单列/可滚动而不错位？
- [ ] 点击目标 ≥44×44px？

## E. 质感与动效（Polish & Motion）—— 反单调核心
- [ ] 是否有至少一处「阴影分层 / 渐变 / 玻璃 / 微动效」亮点？
- [ ] 所有动效用预设缓动（`--ease-out`/`--ease-in-out`/`--ease-spring`），无 `linear`/`all 1s`？
- [ ] 悬停有统一反馈（色变+位移+时长三件套）？
- [ ] 质感克制（≤1–2 处炫技），不处处抢眼？

## F. 可访问性与语义（A11y & Semantics）
- [ ] 使用语义化标签（header/nav/main/section/button 等）与正确的 ARIA？
- [ ] 键盘可达、焦点环清晰（:focus-visible）？
- [ ] 尊重 `prefers-reduced-motion`？
- [ ] 深色主题用带色相的暗色（非纯黑）+ 高光描边？

## G. 风格一致性（Style）—— 呼应 references/
- [ ] 是否按 references/style-archetypes.md 选定了 1 种风格原型，并贯穿全页？
- [ ] 无明显混搭多种气质（既求极简又疯狂渐变）？

---

## 使用提示
- **写代码前**浏览一遍本清单，提前规避。
- **写代码后**逐条打勾，未勾选的项必须修复。
- 若用户已有设计系统，优先用户 token，本清单判断「统一性」时以其为准。
