# 响应式与布局实现（怎么写代码：多端一致）

> 布局要「先移动端思维」，并保证在 手机/平板/桌面 都有统一的美学（对齐、留白、层级）。

## 1. 断点（Breakpoints）
| 断点 | 值 | 说明 |
| --- | --- | --- |
| `--bp-sm` | 640px | 手机横屏/小屏 |
| `--bp-md` | 768px | 平板 |
| `--bp-lg` | 1024px | 桌面窄 |
| `--bp-xl` | 1280px | 桌面宽 |

- 建议 **移动优先**：先写单列基础样式，再用 `min-width` 媒体查询增强到多列。
```css
.grid { display: grid; gap: var(--space-4); grid-template-columns: 1fr; }
@media (min-width: 768px) { .grid { grid-template-columns: repeat(2, 1fr); } }
@media (min-width: 1024px) { .grid { grid-template-columns: repeat(3, 1fr); } }
```

## 2. 容器与边距
- 页面容器限宽 `--container-max`（如 1140px）居中，左右 padding `--container-pad`（桌面 24px，移动 16px）。
- **移动端不留贴边**：至少 16px 左右边距。
- 内容宽度：正文 `.prose` 限 ~66ch，保持可读。

## 3. 流式与弹性布局
- 优先 Grid/Flexbox，**避免固定像素宽度撑爆小屏**。
- 图片/视频 `max-width:100%; height:auto`。
- 长文本用 `overflow-wrap: break-word` / `word-break`（中文可 `overflow-wrap:anywhere`）。
- 栅格用 `minmax()`（如 `repeat(auto-fill, minmax(240px, 1fr))`）获得自然响应。

## 4. 字体与间距响应式
- 大标题字号随视口收缩（clamp）：`font-size: clamp(1.75rem, 1rem + 3vw, 3rem);`
- 大区块间距在移动端可适当缩小（`--space-7/8 → --space-5/6`），保持留白但不过度。
- 行高在移动端（窄屏）可略增。

## 5. 导航响应式
- 移动端折叠为抽屉/汉堡菜单，展开面板 `--bg` + `--shadow-lg`，入场 `--ease-out`。
- 避免侧栏在窄屏挤压内容——侧栏折叠到主内容上方。

## 6. 触控可访问性
- 可点击元素命中区 ≥ 44×44px。
- `:focus-visible` 焦点环清晰（见组件约定 表单 → 聚焦态）。
- `prefers-reduced-motion` 时降低/关闭动效：
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { transition-duration: .01ms !important; animation-duration: .01ms !important; }
}
```

## 7. 响应式自检
- 在 360px 与 1400px 下页面仍对齐、无横向滚动、留白不乱？层级是否保持？
- 表格/多列在窄屏是否降为单列/可滚动而不错位？
- 图片不溢出，字号用 clamp 后是否仍清晰？
