# 质感与动效（怎么写代码：丝滑与「不单调」的关键）

> 质感 = 阴影分层、渐变克制、微交互；动效 = 用**正确缓动+合理时长**让界面「活」起来。
> 这是对抗「单调·死板」最直接的一层。完整缓动示例见 patterns/easing-swatches.md。

## 1. 阴影分层（Elevation）—— 让平面有「高度」
- 用 tokens 的 `--shadow-xs → --shadow-xl` 表达浮起程度（越浮越重）。
- 语义化：卡片 `--shadow-sm`、浮层面板 `--shadow-md/lg`、弹窗 `--shadow-xl`。
- **不要**所有元素用同一块阴影；用阴影深浅制造层次。
- 深色主题：阴影用更透明 + 高光描边（`border-top: 1px solid rgba(255,255,255,.06)`），避免纯黑脏感。

## 2. 悬停微交互（Hover）
给可交互元素「活着」的反馈（三件套：色变 + 位移 + 时长）：
```css
.btn {
  transition: background-color var(--duration-fast) var(--ease-out),
              transform var(--duration-fast) var(--ease-out),
              box-shadow var(--duration-fast) var(--ease-out);
}
.btn:hover { background: var(--color-primary-hover); }
.card-link:hover { transform: translateY(-2px); box-shadow: var(--shadow-md); }
```
- 悬停位移控制在 1–4px（过大显晃）。
- 用 `@media (hover: hover)` 让触屏不误触发。

## 3. 缓动曲线（Easing）—— 丝滑的秘诀
- **永远不要 `transition: all 1s linear` / `ease` 随手用**。
- 推荐预设（见 patterns/easing-swatches.md）：
  - `--ease-out`（多变快收）：进入、弹窗、浮起，最常用。
  - `--ease-in-out`（对称）：展开/收起、宽度变化。
  - `--ease-spring`（弹性）：活泼品牌动效，慎用于功能性控件。
- 时长：微反馈 `150ms`、常规 `250ms`、大动作 `400ms`。**小于 100ms 几乎不可感，大于 600ms 显拖沓**。

## 4. 入场动画（反而要克制）
- 页面/区块入场：淡入 + 轻微上移（`opacity 0→1` + `translateY(8px→0)`），用 `--ease-out`。
- **全部同时播**会乱；用 `animation-delay` 少量错开（100–150ms 递进）。
- 尊重 `prefers-reduced-motion`（见规则 响应式.md）。

## 5. 渐变与质感（克制地使用）
- 大背景渐变：用同色相相邻色（`--color-primary` → 深一号），别用冲突色相。
- 文字渐变（background-clip:text）**慎用**：好看但可读性差，只用于装饰性大标题或 Logo，且保证有后备纯色。
- 玻璃拟态（backdrop-filter）适度：浅色底慎用，深色玻璃效果更好；保持文字对比 ≥ 4.5:1。
- 每页「质感点缀」控制在 1–2 处（一处渐变/一处玻璃/一处动画），避免处处炫技。

## 6. 状态与反馈
- 按钮按下：`translateY(1px)` + 变暗。
- 加载：骨架屏（灰阶 shimmer，`--ease-in-out`）优于转圈；骨架占位保持布局稳定。
- 空状态：图标 + 标题 + 说明 + 操作按钮（可爱但不乱）。

## 7. 质感自检（反单调）
- 页面是否有至少一处「阴影分层 / 渐变 / 玻璃 / 微动效」的亮点？
- 动效是否都用了预设缓动与合理时长，无 `linear` / `all 1s`？
- 悬停是否有统一的三件套反馈？深色是否有高光描边？
- 是否克制不过度（质感 ≤ 1–2 处）？
