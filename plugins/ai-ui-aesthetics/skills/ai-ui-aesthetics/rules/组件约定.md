# 组件约定（怎么写代码：统一性落地）

> 把设计原则落实为**可执行的组件编写规则**。核心：同语义组件全站统一，样式全部引用 token。

## 0. 总体规则
1. 每个组件只表达一种语义层级（主按钮/次按钮/链接/文本要分清）。
2. 同类型组件在全站视觉一致，禁止同一页面出现多种圆角/阴影/按钮样式。
3. 所有颜色/间距/圆角/阴影/动效引用 tokens/design-tokens.md，禁止裸值。

## 1. 按钮 Button
- **主按钮**：`--color-primary` 底 + `--color-text-on-primary` 文字。
- **次要按钮**：白底/透明 + `--color-border` 边框，文字 `--color-text`。
- **幽灵按钮**：无底无边框，仅文字，悬停给 `--color-primary-subtle` 底。
- **链接样式**：`--color-primary` 文字 + 下划线（悬停才显示 or 常显），普通文字不带下划线。
- 统一：圆角 `--radius-md`，内边距 `--space-2 --space-4`，英文全大写按钮 + 小字距 `0.05em`。
- 悬停/按下：渐变压暗（primary-hover）+ `transition`（时长 `--duration-fast`，缓动 `--ease-out`）＋可选轻微 `translateY(1px)` 按压感。

## 2. 卡片 Card
- 统一用 `--color-surface` + `--radius-lg` + 边框 `--color-border` 或 `--shadow-sm`。
- 卡片内 padding 一致（如 `--space-5`）。
- 一张卡片一个语义：单向（展示/点击）尽量整卡可点，避免嵌套可点元素。
- 悬停：微抬升（`transform translateY(-2px)` + `--shadow-md`），时长 `--duration-fast`。

## 3. 表单输入 Input / Select / Textarea
- 统一：`--radius-md`、`--color-border` 边框、内边距 `--space-2 --space-3`、`--color-bg` 底。
- 聚焦态：`2px` 主色边框或主色发光 `box-shadow: 0 0 0 3px var(--color-primary-subtle)`——**清晰可见的焦点环**（可访问性 + 精致感）。
- Label 用 `--color-text-secondary` caption 字号 / 或正文小字，间距 8px。
- 错误态：`--color-error` 边框 + 错误信息用 `--color-error` 小字。
- 占位符用 `--color-text-muted`；禁用态用浅灰底 + muted 文字。

## 4. 导航 / Header / Navbar
- 高度与留白统一（如 64px），左右 padding `--space-5`。
- 当前项高亮：`--color-primary` 或 `--color-primary-subtle` 底。
- 导航链接间距 `--space-4`，悬停用 muted→text 色过渡。
- Header 常定格或滚动吸顶，配合背景模糊（`backdrop-filter`）时慎用——保证可读性。

## 5. 徽章 / 标签 Badge / Tag
- `--radius-sm` / `--radius-full`，小字 `--text-caption`。
- 中性标签：`--color-bg-subtle` 底 + `--color-text-secondary` 文字。
- 状态标签：语义色浅底 + 语义色深字（如 success 用 `#dcfce7` 底 + `#166534` 字）。
- 用语义色**浅底深字**而非纯色块，精致且对比达标。

## 6. 列表 / 表格 Table
- 表头：字重 600、`--color-text-secondary`，下边框 `--color-border`。
- 行分隔线细 `--color-border` 或斑马纹 `--color-bg-subtle`，鼠标悬停行高亮 `--color-primary-subtle`（浅）。
- 数字/代码列用 `--font-mono` 右对齐。
- 单元格 padding `--space-2 --space-4` 一致。

## 7. 弹窗 / 浮层 Modal / Popover
- 覆盖层：`rgba(0,0,0,.4)`，内容面板 `--color-bg` + `--shadow-xl` + `--radius-lg`。
- 入场用 `--ease-out` + `--duration-base`，缩放/淡入（`scale(.98→1)`+opacity）。
- 必须有：标题层级、可关闭按钮、明确可点区。

## 8. 反馈提示 Toast / Alert
- 语义色浅底 + 语义色深字 + 边框（见徽章）。
- 加图标增强辨识；按钮对比清晰。
- 淡入淡出用 `--duration-base` + `--ease-out`。

---

## 组件级「反单调」自检
- 每个区块是否有明确的「主角」元素（主按钮/主数字/主图）？
- 主/次/ghost 按钮是否真的分了层级（颜色/填充/边框）？
- 全站是否只有一套圆角、一套阴影、一种主按钮样式？
